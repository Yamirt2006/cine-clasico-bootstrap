# Archivo del Cine Clásico Universal

Práctica académica de transformación de HTML usando Bootstrap.

## Funciones
- Barra de navegación adaptable a dispositivos móviles.
- Catálogo de seis películas con tarjetas responsivas.
- Buscador de películas y fichas emergentes.
- Secciones de inicio, catálogo, destacadas e historia.

## Publicación
Este sitio está diseñado para alojarse en GitHub Pages desde la rama `main` y la carpeta raíz (`/`).

## Archivos
- `index.html`: página web completa.
